# 飞书机器人外部群配置指南

## 📋 操作前检查

- ✅ 准备好飞书开放平台的登录账号
- ✅ 确保机器人是"企业自建应用"
- ✅ 打开浏览器（推荐Chrome或Edge）

---

## 🚀 详细操作步骤

### 步骤1：登录飞书开放平台

1. 在浏览器地址栏输入：
   ```
   https://open.feishu.cn/app
   ```

2. 使用**企业账号**登录（不是个人账号）

---

### 步骤2：找到机器人应用

1. 登录后，你会看到应用列表
2. 在列表中找到 **"小虾米"** 或你的机器人名称
3. 点击应用卡片进入

📌 **如果找不到应用**：
- 检查是否登录了正确的企业账号
- 确认应用状态是否为"已发布"

---

### 步骤3：进入机器人配置

1. 在应用详情页面，找到左侧菜单：
   ```
   👇 应用能力
      └─ 添加应用能力
         └─ 机器人
   ```

2. 点击 **"机器人"** 进入配置页面

---

### 步骤4：查找外部群权限选项 🔍

在机器人配置页面，查找以下选项（可能的位置）：

#### 位置A：机器人能力卡片
```
┌────────────────────────────┐
│  机器人能力              │
│                          │
│  ☑️ 启用机器人能力      │
│                          │
│  ☑️ 允许添加到外部群 ⚠️ ← 找这个！
│  ☑️ 允许外部用户一对一聊天  │
└────────────────────────────┘
```

#### 位置B：机器人配置区域
```
┌────────────────────────────┐
│  机器人配置              │
│                          │
│  消息接收模式            │
│  ○ WebSocket            │
│  ○ HTTP                 │
│                          │
│  权限设置                │
│  ☑️ 添加到外部群      │ ← 找这个！
│  ☑️ 外部用户聊天        │
└────────────────────────────┘
```

#### 位置C：高级设置
```
┌────────────────────────────┐
│  高级设置              │
│                          │
│  外部访问权限            │
│  ☑️ 允许添加到外部群 ⚠️  ← 找这个！
│  ☑️ 允许外部用户私信   │
└────────────────────────────┘
```

🔔 **注意**：飞书界面可能随版本更新，选项名称和位置可能变化！

---

### 步骤5：勾选外部群权限 ⚠️

**找到以下选项后，务必勾选**：

1. ✅ **"允许添加到外部群"** 或类似选项
2. ✅ **"允许与外部用户一对一聊天"** 或类似选项

📌 **如果找不到这两个选项**：
- 查看应用基础信息 → 应用类型
- 确认是 **"企业自建应用"**
- 如果是"多企业应用"或"ISV应用"，可能不支持外部群

---

### 步骤6：保存配置

1. 在页面底部找到：
   ```
   💾 [保存]  或  [提交]
   ```

2. 点击保存

3. 可能会提示 **"保存成功"** 或自动跳转到应用列表

---

### 步骤7：发布版本

保存后，需要发布新版本才能生效：

1. 在应用详情页，找到：
   ```
   📦 版本管理 → 创建版本
   ```

2. 填写版本信息：
   - 版本号：比如 `1.1`（比当前版本号大）
   - 更新说明：`开启外部群权限`

3. 点击 **"保存"** 或 **"创建版本"**

4. 找到 **"发布"** 或 **"提交审核"** 按钮，点击

5. 企业自建应用通常 **自动通过审核**（1-5分钟内）

## ❓ 常见问题

### Q1：找不到"允许添加到外部群"选项？

**A**：可能原因
1. 应用类型错误（非企业自建）
2. 飞书界面版本更新，选项名称变化
3. 飞书账号权限不足（需要企业管理员）

**解决方案**：
- 联系飞书客服：400-155-8899
- 或在开放平台提交工单
- 说明：企业自建机器人需要开启外部群功能

### Q2：勾选了但发布后还是加不到？

**A**：检查
1. 版本是否已发布（不是仅保存）
2. 是否等待了5-10分钟（发布生效需要时间）
3. 群组是否真的是外部群（不是企业内群）

### Q3：发布时提示需要审核？

**A**：
- 企业自建应用通常自动审核
- 如果提示需要审批，联系企业管理员审批
- 审批时间：通常1-2个工作日
