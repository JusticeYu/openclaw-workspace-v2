# 季度立项数据模板说明

本文件说明进行季度立项时需要准备的数据表格格式。

## 1. 成员系数表 (members_QX_YYYY.xlsx)

记录项目组每个成员的角色和投入系数。

| 字段 | 说明 | 示例 |
|------|------|------|
| 姓名 | 成员姓名 | 张三 |
| 角色 | dev/test/product | dev |
| 系数 | 0.0-1.0，表示投入比例 | 0.8 |
| 备注 | 特殊情况说明 | 兼顾XX项目 |

**示例数据：**

| 姓名 | 角色 | 系数 | 备注 |
|------|------|------|------|
| 张三 | dev | 0.8 | 兼顾其他项目 |
| 李四 | dev | 1.0 | 全职 |
| 王五 | dev | 1.0 | 全职 |
| 赵六 | test | 0.8 | 兼顾其他项目 |
| 孙七 | test | 0.7 | 兼顾其他项目 |
| 周八 | product | 0.5 | 兼顾其他项目 |

---

## 2. 特性清单表 (features_QX_YYYY.xlsx)

记录本季度立项的所有特性。

| 字段 | 说明 | 示例 |
|------|------|------|
| 特性ID | 唯一标识 | FEAT-001 |
| 特性名称 | 简短名称 | 用户登录优化 |
| 描述 | 详细描述 | 优化登录流程... |
| 优先级 | Must/Should/Could/Won't | Must |
| 业务价值 | 1-5分 | 5 |
| 技术复杂度 | 1-5分 | 3 |
| 状态 | 待评审/已立项/已取消 | 已立项 |
| 负责人 | PO姓名 | 张三 |
| 依赖 | 依赖的其他特性 | FEAT-002 |
| 风险等级 | 高/中/低 | 中 |

---

## 3. 用户故事表 (stories_QX_YYYY.xlsx)

记录每个特性拆分出的用户故事及人天评估。

| 字段 | 说明 | 示例 |
|------|------|------|
| 故事ID | 唯一标识 | STORY-001 |
| 所属特性 | 关联特性ID | FEAT-001 |
| 故事描述 | 作为...我想要...以便... | 作为用户，我想要... |
| 验收标准 | 可测试的验收条件 | 1. 登录时间<1秒... |
| 开发人天 | 开发工作量 | 3 |
| 测试人天 | 测试工作量 | 1.5 |
| 需求人天 | 需求工作量 | 0.5 |
| 总人天 | 自动计算 | 5 |
| 负责人 | 主要负责开发人员 | 李四 |
| 状态 | 待开发/开发中/已完成 | 待开发 |

---

## 4. 负荷计算表 (load_calculation_QX_YYYY.xlsx)

汇总计算项目组负荷情况。

| 项目 | 数值 | 说明 |
|------|------|------|
| 季度工作日 | 62 | 来自工作日计算器 |
| 开发系数总和 | 2.8 | 所有开发成员系数之和 |
| 测试系数总和 | 1.5 | 所有测试成员系数之和 |
| 产品系数总和 | 0.8 | 所有产品成员系数之和 |
| 系数总和 | 5.1 | 三项之和 |
| 总可用产能 | 316.2 | 系数总和 × 季度工作日 |
| 计划人天 | 180 | 所有立项故事总人天 |
| 负荷率 | 56.9% | 计划人天 / 总可用产能 |
| 评估结果 | 偏低 | 根据负荷率判断 |
| 剩余产能 | 136.2 | 总可用产能 - 计划人天 |

---

## 快速计算流程

1. **准备成员系数表**，计算各角色系数总和
2. **运行工作日计算器**获取季度工作日
3. **运行负荷计算器**评估负荷情况
4. **根据负荷情况调整**立项特性范围
5. **准备规划报告PPT**，使用生成的模板

---

## 命令速查

```bash
# 计算工作日
python scripts/workday_calculator.py --year 2026 --quarter 2

# 计算负荷（使用参数）
python scripts/capacity_calculator.py \
  --workdays 62 \
  --dev-capacity 2.8 \
  --test-capacity 1.5 \
  --product-capacity 0.8 \
  --total-days 180

# 计算负荷（使用成员文件）
python scripts/capacity_calculator.py \
  --workdays 62 \
  --members-file references/members_example.json \
  --total-days 180

# 生成PPT模板
python scripts/create_ppt_template.py --output my_report.pptx
```
